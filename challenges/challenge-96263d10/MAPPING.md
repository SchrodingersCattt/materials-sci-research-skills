# Mapping: task requirement → skill mechanism → verification check

This file relates each requirement direction of the format/template adaptation topic to the
mechanism in `scripts/adapt_template.py` and to the check that proves it in
`verification.json` or `apply-report.json`. Nothing here is an official scoring claim.

| Requirement direction | Mechanism | Evidence produced |
|---|---|---|
| 认得准 — extract the template's spec as checkable items instead of guessing | `specify` parses the template DOCX (`sectPr`, `docDefaults`, `styles.xml`, table properties) and emits one item per requirement with a `value`, an `evidence_locator` (part + XPath-level description) and a `status` of `extracted` / `not_found` | `spec.json` items: `page_size`, `margins`, `columns`, `default_font`, `default_size`, `styles_*`, `style_mapping`, `source_styles_in_use`, `content_units` |
| 排得对 — heading levels, caption and reference styles are mapped, not merely re-fonted | `apply` imports the template's style definitions and document-wide defaults, then re-points each source paragraph style to the mapped template style; headings map by level (nearest level recorded as an approximation) | `apply-report.json`: `imported_styles`, `restyled_style_pairs`, `document_defaults`; `verification.json`: `style_applied_*`, `template_default_*` |
| 图表与参考文献格式 — three-line tables, caption and reference styles | `apply_table_formatting` copies the template table's formatting (style, borders, layout, cell margins) onto manuscript tables while keeping their widths; caption and reference styles map through the same style-role logic | `verification.json`: `template_table_style`; `spec.json`: `styles_caption`, `styles_reference` |
| 转得全 — nothing is deleted, merged or rewritten by the conversion | the whole package is copied member by member and only `word/styles.xml` and `word/document.xml` are edited in place; the paragraph text stream is compared before and after the edit and the run refuses to publish on any difference | `apply-report.json`: `content_stream_preserved`, per-member copy list, `not_rebuilt`; `verification.json`: `content_coverage`, `content_order`, `preserved_table_count`, `preserved_image_relationships`, `preserved_has_footnotes/endnotes/comments/equations/tracked_changes/fields` |
| 交得出 — an openable, editable result with usable page setup and a real preview | the output stays a normal DOCX package (same parts, `[Content_Types].xml` intact); page size, margins, columns and grid come from the template; `preview` renders a real PDF/PNG through LibreOffice+Poppler when present, and otherwise states the missing renderer instead of claiming a preview | `verification.json`: `openable_package`, `template_page_size`, `template_margins`, `template_columns`; `preview-report.json`: `pdf`, `pngs`, `pdf_font_report`, `note` |
| Honesty and limits | refused operations carry a `reason` and exit code 2; unmatched styles are listed rather than dropped; prose-only requirements, font substitution, numbering and cross-reference behaviour and any unchecked item are stated as limitations | `apply-report.json`: `reason`, `unmapped_styles`; `verification.json`: `failed` count and per-check `evidence` |
