# Period 4 contest deliverables

Public source for submissions to the **Bohrium AI Product Weekly Contest**, period 4
(2026-11-18 to 2026-11-25). One folder per challenge, named by its challenge id.

Each folder holds the skill package submitted for that challenge: `SKILL.md` plus the scripts,
templates and tests it actually runs. The contest statement is asked to bound skill resources at 50
UTF-8 text files, 500 KB each and 2 MB total, so the packages are deliberately small and depend on
the standard library and the sandbox's declared `scientific-python` toolchain.

These are contest submissions, not a general-purpose library. The reusable engineering lives in the
sibling skills in this repository (`visualize-data`, `grill-research`), which are the ones worth
reading if you are here for the technique rather than a specific entry.
