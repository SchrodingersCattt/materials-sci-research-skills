# Per-figure check list

- [ ] every plotted value is declared in the data source, with its unit
- [ ] axes carry the declared unit and the declared scale
- [ ] error bars state their convention (SD / SEM / CI / none)
- [ ] the caption states what is plotted, for what condition, at what n
- [ ] the exported file is the real format (vector or bitmap), not a renamed text file
- [ ] the rendered preview was opened and checked for clipping and legibility
