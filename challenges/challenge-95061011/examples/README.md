# Synthetic interface example

All three studies and values here are invented. Run `python3 ../scripts/check_matrix.py targets.json sources.json results.json` from this directory. Under the deliberately supplied identical labels for A and B the checker reports a 5 percentage-point arithmetic difference subject to scientific review. It marks comparisons with C noncomparable because the pollutant differs. Equal labels alone do not prove comparable experiments; this fixture is neither an organizer case nor evidence of benchmark performance.
